# Who can write here

The brain is **off by default in every project.** A Claude Code session may read and write
these notes only when the project it's running in has been *connected* — that is, when the
project's own `CLAUDE.md` carries the connection block (added by `npx better-brain
connect`).

This is the gate that stops an unrelated project from silently reading your identity or
writing into your knowledge base. Silence means not connected.

## Connected projects

> Run `npx better-brain connect` inside a project to connect it, then list it here so
> other sessions know it exists. This list is `volatile` — keep it honest.
